# 实验五 GDSC–Ridge Li–Niu 分数对照

五规则使用相同的 GDSC 数据、预处理、749/188划分、17737列、alpha=17737及完整系数恢复。六个预算各采用30次 LN_floor 抽样，180条 LN_floor 指标与稳定 V 的720条 UNI/NORM/LEV/OPT 指标组成900条配对对照。180份共同随机数与稳定 V 保存记录及种子202610310501逐项相等。

两种分数均使用 pi_j=max(0.01/p,tau*s_j)。这是共同概率下界下的 oracle 分数比较，未实现 Li–Niu 原文的 NOPL 或外层迭代。

## 确定性诊断与结论

概率总变差距离0.03119715；OPT相对LN_floor的一阶完整系数准则降低0.646970%。这比既有模拟消融的准则差距大，但当前真实数据仍未展示清楚的有限预算经验优势。理论最优性针对指定一阶准则，不能扩大为每个预算的误差严格更低。

原稳定V的78/78仅比较UNI/NORM/LEV/OPT。加入LN_floor后，GDSC–Ridge在N=374、749出现更低的LN均值；78/78 不适用于包含 LN_floor 的五规则比较。预测指标另行保留，不能用系数目标误差替代预测收益。

180个 LN_floor 状态逐一通过显式系数、Gram和QR坐标核对；最大坐标误差相对差异2.02e-15，最大SPD求解归一化残差5.34e-17。独立分析核对全部900条指标、30个均值及6个配对区间，并使用原预处理输入核验180个 LN_floor 状态。保存指标复核仅计算这些汇总和核验量，不执行估计量求解。
