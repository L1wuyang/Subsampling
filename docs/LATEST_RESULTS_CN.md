## 2. Ridge 列抽样：Li–Niu 分数与完整系数分数

完成 40 份既有输入、13 个预算、40 次重复、5 种规则，共 104,000 条记录；无数值失败，独立二次型误差核验通过。采用共同下界约束的 LN_floor，未复现原文外层迭代或 NOPL。

预设唯一主比较 N=150：

| 抽样规则 | 平均相对平方误差 |
|---|---:|
| UNI | 0.46852476 |
| NORM | 0.11064956 |
| LEV | 0.11647983 |
| LN_floor | 0.07697390 |
| FULL_OPT | 0.07665110 |

FULL 相比 LN 的平均误差降低约 0.419%；40 份数据中 26 份更低。配对差值 FULL−LN=-0.000322806，95% CI=[-0.000942379, 0.000296766]，双侧 p=0.2984。区间跨零，未检出显著差异；不等于已证明两者等价。

确定性诊断：LN 与 FULL 的概率总变差距离均值 0.002990，范围 [0.002291, 0.004290]；FULL 相比 LN 的一阶系数准则降低均值 0.006058%，范围 [0.003262%, 0.011598%]。说明当前输入与正则化设置本来就让两种规则形成的概率向量和一阶准则非常接近；这一点与经验曲线近乎重合相符。

FULL 的理论优势是最小化指定的一阶完整系数准则，并不保证每一有限样本误差严格更低。当前实验支持两种目标相关分数相对 UNI/NORM/LEV 的优势，尚不足以支持完整分数显著优于 Li–Niu 分数的结论。各预算描述性结果保留轻微反转，未更换主比较或选择有利预算。

校准图中，两种规则的经验误差/一阶预测从小预算约 1.58 降至最大预算约 1.12，体现有限预算高阶效应随预算增加减弱；尚非精确有限样本公式。复用既有数据，不能称为新数据独立确认；未测端到端总成本，不报告加速比。

## 3. 实验五 GDSC–Ridge Li–Niu 分数对照

五规则使用相同的 GDSC 数据、预处理、749/188划分、17737列、alpha=17737及完整系数恢复。六个预算各采用30次 LN_floor 抽样，180条 LN_floor 指标与稳定 V 的720条 UNI/NORM/LEV/OPT 指标组成900条配对对照。180份共同随机数与稳定 V 保存记录及种子202610310501逐项相等。

两种分数均使用 pi_j=max(0.01/p,tau*s_j)。这是共同概率下界下的 oracle 分数比较，未实现 Li–Niu 原文的 NOPL 或外层迭代。

## 确定性诊断与结论

概率总变差距离0.03119715；OPT相对LN_floor的一阶完整系数准则降低0.646970%。这比既有模拟消融的准则差距大，但当前真实数据仍未展示清楚的有限预算经验优势。理论最优性针对指定一阶准则，不能扩大为每个预算的误差严格更低。

原稳定V的78/78仅比较UNI/NORM/LEV/OPT。加入LN_floor后，GDSC–Ridge在N=374、749出现更低的LN均值；78/78 不适用于包含 LN_floor 的五规则比较。预测指标另行保留，不能用系数目标误差替代预测收益。

180个 LN_floor 状态逐一通过显式系数、Gram和QR坐标核对；最大坐标误差相对差异2.02e-15，最大SPD求解归一化残差5.34e-17。独立分析核对全部900条指标、30个均值及6个配对区间，并使用原预处理输入核验180个 LN_floor 状态。保存指标复核仅计算这些汇总和核验量，不执行估计量求解。

仅对GDSC的Ridge列抽样补充。Year为行抽样，其他生成子和实验四维持既定任务；未运行额外调参、预算搜索或成本实验。完整记录和核验回执随当前仓库保存。


## 4. 结论与证据范围

实验五提供经过全支撑稳定性检查的真实数据经验比较，支持在固定数值目标下评估各抽样规则。Li–Niu 分数对照说明，完整系数影响分数与原分数在这些输入上形成的概率及一阶准则较接近；模拟主比较未检出显著差异，GDSC 结果保留预算反转和跨零区间。两项对照均未显示清楚的有限预算经验优势。

LN_floor 是共同概率下界下的精确 oracle 分数。NOPL 近似和 Li–Niu 原文外层迭代不在本实验范围内。系数目标近似、真实系数恢复和测试预测分别评价；固定数据的配对 Monte Carlo 区间也与跨数据集的主比较区间分别报告。
