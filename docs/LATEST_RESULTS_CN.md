## 2. Ridge 列抽样：Li–Niu 分数与完整系数分数

完成 40 份既有输入、13 个预算、40 次重复、5 种规则，共 104,000 条记录；无数值失败，独立二次型误差核验通过。采用共同下界约束的 LN_floor，未复现原文外层迭代或 NOPL。

预设唯一主比较 N=150：

| 抽样规则 | 平均相对平方误差 |
|---|---:|
| UNI | 0.46852476 |
| NORM | 0.11064956 |
| LEV | 0.11647983 |
| LN_floor | 0.07697390 |
| FULL_OPT | 0.07665110 |

FULL 相比 LN 的平均误差降低约 0.419%；40 份数据中 26 份更低。配对差值 FULL−LN=-0.000322806，95% CI=[-0.000942379, 0.000296766]，双侧 p=0.2984。区间跨零，未检出显著差异；不等于已证明两者等价。

确定性诊断：LN 与 FULL 的概率总变差距离均值 0.002990，范围 [0.002291, 0.004290]；FULL 相比 LN 的一阶系数准则降低均值 0.006058%，范围 [0.003262%, 0.011598%]。说明当前输入与正则化设置本来就让两种规则形成的概率向量和一阶准则非常接近；这一点与经验曲线近乎重合相符。

FULL 的理论优势是最小化指定的一阶完整系数准则，并不保证每一有限样本误差严格更低。当前实验支持两种目标相关分数相对 UNI/NORM/LEV 的优势，不能支撑“完整分数显著优于 Li–Niu 分数”的卖点。各预算描述性结果保留轻微反转，未更换主比较或选择有利预算。

校准图中，两种规则的经验误差/一阶预测从小预算约 1.58 降至最大预算约 1.12，体现有限预算高阶效应随预算增加减弱；尚非精确有限样本公式。复用既有数据，不能称为新数据独立确认；未测端到端总成本，不报告加速比。

## 3. 实验五新增 GDSC–Ridge Li–Niu 分数对照（2026-11-01）

沿用实验五的数据、预处理、749/188划分、17737列、alpha=17737及完整系数恢复。新增6个既定预算×30次 LN_floor 抽样，共180条新指标；与既有720条四规则指标组成900条对照。目标、旧规则概率及旧结果未改。180份共同随机数均与已保存记录及种子202610310501逐项完全相等。

两种分数均使用 pi_j=max(0.01/p,tau*s_j)。这是共同概率下界下的 oracle 分数比较，未实现 Li–Niu 原文的 NOPL 或外层迭代。

## 确定性诊断与结论

概率总变差距离0.03119715；OPT相对LN_floor的一阶完整系数准则降低0.646970%。这比既有模拟消融的准则差距大，但当前真实数据仍未展示清楚的有限预算经验优势。理论最优性针对指定一阶准则，不能扩大为每个预算的误差严格更低。

原稳定V的78/78仅比较UNI/NORM/LEV/OPT。加入LN_floor后，GDSC–Ridge在N=374、749出现更低的LN均值；不能继续把78/78写成包含Li–Niu的新全规则排序。预测指标另行保留，不能用系数目标误差替代预测收益。

180个新状态已逐一用显式系数、Gram和QR坐标核对；最大坐标误差相对差异2.02e-15，最大SPD求解归一化残差5.34e-17。独立汇总脚本重新核对900条指标、30个均值及6个配对区间，并核验180个新状态；没有增加实验求解。全部消耗输入与旧结果哈希保持不变。

仅对GDSC的Ridge列抽样补充。Year为行抽样，其他生成子和实验四维持既定任务；未运行额外调参、预算搜索或成本实验。完整记录和核验回执随当前仓库保存。


## 4. 对论文的直接含义

实验五可提供带全支持稳定性依据的真实数据经验验证，保留有限重复和一阶理论边界。Li–Niu 对照应如实报告接近的表现及不显著主比较，适合用于交代分数关系与适用范围；模拟和GDSC固定真实数据均未展示清楚的完整分数有限预算经验增益。不据此改选预算、删去反转或自动另跑数据。模拟分数对照和新增GDSC Ridge直接比较均已写入正文、补充及对应图表，对应代码、协议和保存证据随当前仓库提供。
