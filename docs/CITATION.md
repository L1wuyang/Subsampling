> Junchen Li, Ying-Ao Wang and Ye Zhang. *Optimal Subsampling for Regularized Linear Regression: A Generator-Function Framework*. Manuscript, 2026.

```bibtex
@unpublished{li2026optimal,
  author = {Li, Junchen and Wang, Ying-Ao and Zhang, Ye},
```

When identifying the computational materials, include the repository address and the exact commit used:

```text
Repository: https://github.com/L1wuyang/Subsampling
Version:    output of git rev-parse HEAD
```

The manuscript's fixed code link should identify a commit containing the files cited in its data and code availability statement. `MANIFEST.json` supplies file-level checksums for that version.

引用论文时请使用上述作者、题名及稿件信息；引用实验材料时同时记录仓库地址与 `git rev-parse HEAD` 返回的完整提交号。论文中的固定代码链接应指向实际包含所引用材料的提交，文件级校验和见该版本的 `MANIFEST.json`。
